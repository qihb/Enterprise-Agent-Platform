# 企业 Agent 平台 · 0 到 1 落地计划

**目标**：为约 4000 人的集团建设可治理、可追溯、可扩展的 Agent 知识与工具访问平台，并先交付一个边界清晰的只读领域 MVP。

**技术栈**：首版采用 TypeScript 全栈；具体前端、后端、存储、模型和部署选型在阶段 0 确认。

**涉及文件**：项目入口、总体架构、架构决策、后续应用与服务代码、连接器、检索、权限、评测和部署配置。

**关键决策**：需确认首期业务域、数据源、身份权限来源、部署环境、模型供应商和数据合规要求。

**执行约定**：本文件仅为计划；用户确认后，按用户指定的阶段执行。每完成一步更新勾选状态、变更文件和验证结果。

## 阶段 0 · 需求、治理与技术选型

- [ ] 0.1 选择首期试点业务域和 2 到 3 个核心用户场景
- [ ] 0.2 盘点文档、数据库、业务系统和 API 数据源
- [ ] 0.3 建立数据分级、文档负责人、版本和过期规则
- [ ] 0.4 确认身份、组织架构、权限模型和审计要求

- [ ] 0.6 建立 100 条左右的真实问题评测集和验收指标

## 验收指标

- 正确资料召回率
- 引用支持率
- 越权回答数：目标为 0
- 无答案时的正确拒答率
- 平均响应时间和单位请求成本
- 用户采纳率与人工转交率
- 文档同步成功率和过期资料比例
