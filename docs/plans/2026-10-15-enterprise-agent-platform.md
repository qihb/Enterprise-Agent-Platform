# 企业 Agent 平台 · 0 到 1 落地计划

**目标**：为约 4000 人的集团建设可治理、可追溯、可扩展的 Agent 知识与工具访问平台，并先交付一个边界清晰的只读领域 MVP。

**技术栈**：首版采用 TypeScript 全栈；DeepSeek API + Model Gateway；PostgreSQL + pgvector，关键词检索采用应用侧中文分词；本地中文 Embedding + RRF 排序融合；本地受控文件存储，后续适配阿里云 OSS。先本地验证，后续部署到境内阿里云。前后端框架在阶段 1.1 的工程初始化方案中确认。

**涉及文件**：项目入口、总体架构、架构决策、后续应用与服务代码、连接器、检索、权限、评测和部署配置。

**关键决策**：首期业务、身份、同步、问答模型、检索与存储及部署方向已确认。中文分词、Embedding 运行组件和性能需实现阶段验证；模型数据合规要求和云端具体配置须生产部署前确认。

**执行约定**：本文件仅为计划；用户确认后，按用户指定的阶段执行。每完成一步更新勾选状态、变更文件和验证结果。

## 验收指标

- 正确资料召回率
- 引用支持率
- 越权回答数：目标为 0
- 无答案时的正确拒答率
- 平均响应时间和单位请求成本
- 用户采纳率与人工转交率
- 文档同步成功率和过期资料比例
