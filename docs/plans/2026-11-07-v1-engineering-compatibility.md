**目标**：建立可启动、可构建、可测试的工程骨架，验证数据库、中文 PDF 提取和本地向量计算能在本机配合工作。
**记录日期**：2026-11-07。
**方案依据**：[V1 技术架构方案](../architecture/evolution-plan.md#8-v1-技术架构方案--待确认)、[版本路线](iteration-roadmap.md)。
**技术栈 / 约束**：TypeScript、PostgreSQL + pgvector、本地中文 Embedding；推荐 Next.js + 同仓库 Node.js 计算进程，框架与具体依赖仍待确认。
**执行约定**：按用户要求单独记录本步骤。创建计划不代表授权编码、安装依赖或下载模型；用户指定子步骤后才执行，每完成一项更新勾选、验证结果和已知限制，不自动推进下一项。

## 1. 环境核对

- [ ] 1.1 只读检查 Node.js、包管理器、PostgreSQL 和 pgvector 的实际版本及可用性。
- [ ] 1.2 记录本机硬件、内存、可用磁盘及已有数据库连接方式，连接记录不包含密码。
- [ ] 1.3 根据实际结果确认兼容组合与需要用户授权的准备操作，不擅自升级或覆盖现有环境。

**验收**：版本与资源有实际检查记录，兼容风险和未验证项明确。命令失败只报告完整命令、用途及实际报错，不推断未安装。
**涉及文件**：本计划的验证记录；本阶段不创建业务代码。

## 2. 工程初始化

- [ ] 2.1 创建确认后的 Next.js + TypeScript 最小工程，按功能组织目录，不创建未使用的后续模块。
- [ ] 2.2 配置类型检查、测试、环境变量模板、依赖锁文件和 Git 忽略规则；环境模板只包含示例值。
- [ ] 2.3 提供最小启动页面，验证开发启动、类型检查、测试及生产构建。

**验收**：上述检查实际通过，应用仅回环监听；最小页面不是完整资料页或问答页。
**预计涉及文件**：`package.json`、所选包管理器锁文件、`tsconfig.json`、Next.js / 测试配置、`.env.example`、`.gitignore`、`src/app/`、`README.md`。

## 3. 数据库连通

- [ ] 3.1 确认隔离测试数据库与操作范围，实现服务端连接配置和版本化迁移入口。
- [ ] 3.2 编写集成测试并验证真实连接、参数化全文查询、向量写入及相似度查询。
- [ ] 3.3 验证连接失败有明确结果、日志不泄露凭据；测试数据只在授权的隔离范围内清理。

**验收**：真实 PostgreSQL + pgvector 查询通过，不以 mock 代替；本项不创建完整文档、ACL 或任务业务表。
**预计涉及文件**：`src/db/`、`src/db/migrations/`、`tests/integration/`、环境模板。

## 4. PDF 解析验证

- [ ] 4.1 选用获准、无敏感的中文文字 PDF、英文/编号混排 PDF 和含扫描页 PDF，核查解析库许可与 Node.js 兼容性。
- [ ] 4.2 先写失败测试，再实现最小提取适配器，按页输出文字与从 1 开始的物理页码。
- [ ] 4.3 人工核对选定页的中文、阅读顺序、换行和页码，验证扫描页、损坏及加密 PDF 的明确结果。

**验收**：页码正确、文本质量可核对；无文字页不冒充完整提取，解析失败可识别。
**预计涉及文件**：`src/adapters/pdf/` 及相邻测试；中间实验材料放在仓库外，持久测试夹具只纳入获准的小型非敏感样本。

## 5. 本地向量与分词验证

- [ ] 5.1 核查候选模型、ONNX 制品、分词器的版本、来源与许可；获准后下载并记录模型 revision 和哈希。
- [ ] 5.2 先写失败测试，再实现最小 Embedding / 分词适配器，验证维度、tokenizer、pooling、归一化和问题前缀。
- [ ] 5.3 用约十个样本问题做小规模证据召回实验，检查中文词语、英文和错误码，记录内存、冷启动及热查询耗时。

**验收**：锁定可复现的模型输入与分词约定；重启可加载本地制品，运行期禁止自动远程下载。小样本实验不是完整 RRF 产品或正式质量评测。
**预计涉及文件**：`src/adapters/embedding/`、`src/modules/retrieval/` 中的分词契约及相邻测试；模型制品保存在 Git 之外。

## 6. 计算进程与交付检查

- [ ] 6.1 建立计算进程启动入口、健康检查和仅回环监听的最小计算接口，校验独立内部凭据。
- [ ] 6.2 验证应用经内部接口完成向量计算；检查未授权调用、进程不可用和请求超时的明确结果。
- [ ] 6.3 复查构建、测试和本地联通，补齐启动顺序、停止方式、配置及故障说明，更新本计划验收状态。

**验收**：应用、计算进程和数据库可分别启动，最小联通测试通过；不提前实现任务领取、重试或导入恢复。
**预计涉及文件**：`src/compute/main.ts`、内部接口及客户端、对应测试、`README.md`。

## 范围与完成条件

本步不实现上传管理、持久导入任务及恢复、完整问答、引用展示、飞书、云部署或生产备份。候选组件不合格时记录证据并重新比较，由用户确认替代路径。
