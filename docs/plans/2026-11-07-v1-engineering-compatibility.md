### 本次初始化方案（2026-11-09，已确认，已完成）

**目标与授权边界**：本次仅执行 2.1～2.3，交付可启动、可检查、可测试、可生产构建的网页工程。确认后允许安装本阶段 npm 依赖并生成锁文件；不包含建库、启用扩展、下载模型、调用 DeepSeek、Git 提交或自动推进第 3～6 节。

**建议组合**：Next.js App Router + React + TypeScript 严格模式、pnpm 10、Vitest、ESLint；使用现有 Node 24.11.0，通过 `.nvmrc` 固定项目版本，不修改其他项目或全局默认版本。不使用 monorepo 工具，计算进程仍在同仓库，但其入口留到第 6 节实现。

| 选择 | 收益与代价 | 建议与反转条件 |
| --- | --- | --- |
| 现有 Node 24.11.0 或 22.14.0 | 两者均满足此次查询到的 Next.js / Vitest engines；切换后仍需实际安装与构建验证 | 建议 Node 24；若后续 PDF / ONNX 实测不兼容，再比较 Node 22，不提前承诺全部依赖兼容 |
| 保持当前 Node 20.19.1 | 少一次版本切换，但不能安装此次查询到的 Vitest 5.1.0，须另选旧版测试工具并核查维护情况 | 本次不推荐；仅有必须保留 Node 20 的约束时重新比较 |
| pnpm 或 npm | 两者已安装；pnpm 沿用既有准备，npm 可减少对其他包管理器的依赖，二者都需锁文件 | 建议 pnpm 10.10.0，只维护 `pnpm-lock.yaml`；不混用包管理器 |
