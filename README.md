# Enterprise Agent Platform

集团级 Agent 知识与工具访问平台的架构与实施项目。

## 项目目标

面向约 4000 人的集团组织，建设一套可治理、可追溯、可扩展的企业 Agent 平台：

- 用 Skill 定义 Agent 的工作流程；
- 用 References 保存结构化的领域资料；
- 用混合检索访问大规模知识；
- 用 MCP 访问企业系统和业务工具；
- 用统一权限、审计和评测保障生产可用性。

## 技术路线

首版采用 TypeScript 全栈路线，先在本地验证，后续部署到境内阿里云：

- 问答：DeepSeek API，经 Model Gateway 执行策略校验与调用管理。
- 检索：PostgreSQL + pgvector，应用侧中文分词与向量召回后使用 RRF 排序融合。
- 向量生成：本地中文 Embedding，首期不部署独立语义重排序模型。
- 文件：本地受控存储，后续通过适配器接入阿里云 OSS。

前后端框架在阶段 1.1 的工程初始化方案中确认。中文召回效果和本地模型资源需求仍需验证；本地运行也不免除 DeepSeek API 外发数据的合规要求，严格受限内容禁止发送给外部模型。

## 协作约定

核心 AI 规范：[agent.md](agent.md)。重要技术决策必须先分析场景，提供方案优劣、阶段适用性、验证证据与迁移代价的对比，再由用户确认；长期架构演进按实际瓶颈和复审条件推进，不默认提前升级。

本项目遵循“先确认计划，再按指定阶段执行”的协作方式。每完成一个阶段，都要同步更新计划文档、验证结果和待办事项。
